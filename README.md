# Каталог

Статический одностраничный каталог для GitHub Pages.

- `index.html` — сам каталог (сетка 4 фото в ряд, клик — увеличение)
- `catalog.js` — порядок фото и номера моделей
- `prices.js` — **цены**, единственный файл, который нужно править
- `img/` — полноразмерные фото, `thumb/` — превью

## Как поменять цену

Откройте `prices.js`, впишите число между кавычками:

```js
"img_6292.jpg": "530",
```

Пустая строка `""` показывается как «Цена по запросу».

Либо используйте локальную админку (`admin.html` в папке models на компьютере):
вводите цены в форму, нажмите «Скачать prices.js» и замените этот файл здесь.
